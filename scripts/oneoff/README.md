# Engångsskript

Diagnostik-, backfill- och migreringsskript som skrevs för specifika
incidenter eller engångsmigreringar. De behålls som referens men ingår
inte i någon driftrutin — kör dem inte utan att läsa koden först.

Skript som ingår i drift (seeding, kunskapsimport) ligger kvar i `scripts/`.
